# This repository is for the Fabric version of APEx - A Proper Equipment Expansion. The Forge version can be found [here](https://github.com/ifound1dollar/MC_Forge_APEx).

APEx - A Proper Equipment expansion is a Minecraft: Java Edition mod that adds interesting and powerful choices to early, mid, and end-game gearing. It intends to make the equipment progression system less linear by offering different choices for gear at various stages of the game.

The mod's Wiki details all mod features and can be found [here](https://github.com/ifound1dollar/MC_Fabric_APEx/wiki).

Compiled, plug-and-play .jar file available on Curseforge ([link](https://www.curseforge.com/minecraft/mc-mods/apex-a-proper-equipment-expansion)) and Modrinth ([link](https://modrinth.com/mod/apex-a-proper-equipment-expansion)).
